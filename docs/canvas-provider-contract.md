# 画布能力契约与插件状态

## 配套源码定位

遵守根目录 AGENTS.md：优先当前用户指定路径，其次本机 `CANVAS_SOURCE_ROOT`，再查找同级画布仓库。路径不进入业务代码或版本控制中的机器配置。

## 模型参数

画布能力接口提供 `schemaVersion: 1`、`definitionsByModel[modelId]` 时，插件采用该模型完整的节点定义，包括输入限制和递归字段联动；旧画布版本继续使用原适配逻辑。画布的 Provider 参数事实留在各自 Bundle，插件不复制新模型参数表。

提示词与参考图按后端地址、项目隔离，模型参数在此基础上按节点类型和模型保存；旧存储在读取时迁移到地址隔离的键。切回 Provider 恢复上次模型。参数联动调整会提示，生效字段与最终提交使用同一份解析结果。可选数字留空表示不提交，未声明上下限时不会注入通用控件的 0–100 限制。

## 连接与任务

连接控制器是单实例，设置页只展示与修改配置。请求序号防止旧响应覆盖新连接；能力目录失败与服务连接失败分别展示。只在首次初始化或用户明确连接、刷新、查找时读取目录。

任务在任何异步操作前固定后端、项目、模型、参数及 Photoshop 文档/边界。参考图准备期间暂时锁定模型、项目、连接和表单；上传回写同步完成后释放锁，允许编辑下一次参数。任务进度独立展示所属项目与模型，切换设置或 Provider 不丢失取消入口。上传会话按表单实例隔离，卸载后停止旧上传回写，取消不移除仍挂载控件的自动采集注册。

参考图超限时保留全部草稿并提示，提交时检查实际数量。新旧模型之间不会通过截断显示来掩盖多余输入。

## 针对性验证

在 `packages/sdppp-photoshop` 使用已安装的 Vitest 运行 `vitest run --config vitest.canvas.config.ts`。配置不加载开发 Vite 插件，也不启动服务。覆盖能力解析、任务快照、取消竞态、连接事务、上传隔离与同步回写。

画布侧运行能力路由与 `image-client-contract.test.ts`，并按其 Bundle 指南检查 Shared 构建及相关迁移测试。反向定位插件使用本机 `CANVAS_PLUGIN_SOURCE_ROOT` 或同级目录，不写入个人绝对路径。
